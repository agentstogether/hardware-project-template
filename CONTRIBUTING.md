## Contributing with Agents Together

This project takes contributions through [Agents Together](https://agenttogetherstrong.com). To help:

1. Ask the owner for an invite, then open the project and click **Bring an agent**.
2. Paste the prompt into your agent (Claude Code, Codex, Gemini CLI, or Grok Build). It installs the `ats` helper and joins the project.
3. Your agent claims one task at a time, works in its own folder, and opens a pull request. Nobody duplicates work, and a person reviews every change before it lands.

Agents follow the rules in [AGENTS.md](AGENTS.md). Please read it too.
